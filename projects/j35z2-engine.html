Honda J35Z2 V6 engine study.

A developing CAD and motion-study project focused on the mechanisms inside the 3.5L V6 in my Honda Accord. I'm using Fusion 360 and Python to move from a working crank-slider prototype toward a complete, documented V6 assembly.

PROJECT BRIEF · 00

From a working mechanism to a complete V6 study

The goal is to create an explanatory virtual model of the Honda J35Z2 3.5L V6, showing how its major mechanical systems work together. The project is being developed in stages, with motion and dimensions checked before additional complexity is introduced.

MILESTONE 01 · WORKING PROTOTYPE

Crank-slider mechanism

This first prototype demonstrates how crank rotation produces reciprocating piston motion. The simplified assembly contains a piston, wrist pin, connecting rod, and crank throw positioned using slider-crank kinematics.

Current implementation

Python automation exports 72 frames at 5° crank-angle increments; a Python/Pillow workflow assembles them into a looping GIF. This is a simplified kinematic prototype, not a complete engine assembly.

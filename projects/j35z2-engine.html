WORK IN PROGRESS · SINGLE-CYLINDER PROTOTYPE

Honda J35Z2 V6 engine study.

A developing CAD and motion-study project focused on the mechanisms inside the 3.5L V6 in my Honda Accord. I'm using Fusion 360 and Python to move from a working crank-slider prototype toward a complete, documented V6 assembly.

Project overview

The goal is to create an explanatory virtual model of the Honda J35Z2 V6: not just a static engine render, but a set of views showing how the crankshaft, pistons, connecting rods, camshafts, and valves work together. The model will grow in stages so the motion can be checked before more detail is added.

Current milestone

A single-cylinder crank-slider prototype is working in Fusion 360. It contains a piston, wrist pin, connecting rod, and crank throw positioned using slider-crank kinematics. A Python export workflow renders numbered PNG frames, and a separate utility combines them into a seamless looping GIF.

01 · GeometryPiston, wrist pin, connecting rod, and crank throw assembled as a first prototype.
02 · MotionA full crank revolution exported as 72 frames at 5° crank-angle increments.
03 · WorkflowFusion 360 Python API for model/frame generation; standard Python and Pillow for GIF creation.
04 · NextExpand to a mechanically coherent six-cylinder layout and synchronize all piston motion.

Development plan

  • Full V6 bottom end: build the cylinder-bank layout, a coherent crankshaft, six pistons, six connecting rods, and synchronized motion.
  • Four-stroke cycle: visualize the 720° operating cycle and cylinder phasing, rather than treating one crank revolution as the complete cycle.
  • SOHC valvetrain: add the two camshafts, valve motion, timing relationship, and explanatory close-up views.
  • i-VTEC and timing drive: research the J35Z2-specific mechanism and implement a clearly labeled model of its operating behavior.
  • Engineering outputs: create displacement, velocity, acceleration, and valve-lift plots, plus exploded and cutaway views.

Validation & scope

The project will distinguish published engine specifications, mathematically derived values, physical measurements, and estimated component dimensions. The current animation is a kinematic visualization of a simplified mechanism; it is not a combustion, thermal, structural, or CFD simulation.

The single-cylinder prototype is a working milestone, not yet a complete J35Z2 engine model. Detailed internal dimensions, crankshaft phasing, and valvetrain behavior will be verified where reliable technical references are available; estimates will be documented rather than presented as OEM measurements.

Planned validation includes checking the modeled piston stroke, connecting-rod length, piston-axis alignment, crank-angle relationships, and consistency between the analytical kinematics and exported frames. Any future physical or dynamic simulation will be treated as a separate stage requiring appropriate inputs and validation.

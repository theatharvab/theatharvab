## Research

### Physics-Informed ML for Regenerative Cooling-Channel Optimization

An independent research project exploring machine-learning-assisted optimization of regenerative cooling channels for liquid-methane rocket engines.

The project combines **OpenFOAM CFD**, **PyTorch**, and numerical optimization to develop a fast surrogate model for predicting cooling-channel performance and exploring large design spaces.

**Focus areas:**

* Regenerative cooling
* Computational fluid dynamics
* Machine learning
* Thermal management
* Engineering optimization
